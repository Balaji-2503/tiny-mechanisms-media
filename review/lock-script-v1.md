## Caption (draft)
"Why does only ONE key open this?" Inside a pin tumbler lock, a spring pushes pairs of pins down. The right key lifts every pin to exactly the same line; only then can the plug turn. A key that is right for four pins out of five still stays locked. Example: 5 pins x 6 possible heights = 7,776 combinations (an illustration, not a real lock model). Source: US Patent 31,278 (Linus Yale Jr., 1861). Save this for later.
